# pi-redkit

授权渗透测试与网络/协议逆向的提示词注入扩展：把一套作战条令钉进 Pi 的系统提示词，每次 agent 循环启动前重注入，压缩（compaction）后条令依然在场。

当前阶段只交付提示词注入。工具、scope 守卫、技能与提示词模板后续挂载。

## 注入内容

条令按"威胁建模优先 → 薄切片推进 → oracle 证据纪律"组织：

- **授权事实**：交战已完成书面授权，用户给出的目标即授权范围，模型不再反复确认合法性；
- **工作方法**：威胁建模优先（入口点/信任边界/攻击者模型/历史漏洞模式）、薄切片、不变量分解、对比基准实现、盯修复找绕过；
- **推理框架**：假定 breach、要 exploit 不要评估、反转提问、迭代施压；
- **证据纪律**：file:line + 调用链 + oracle 判定神谕、先证伪再上报、PoC 必须真实运行，confirmed / hypothesis 分级；
- **渗透条令**（pentest/full）：侦察即建图、Web/API 切片优先级、确认即收束、凭据即时记录；
- **网络与协议逆向条令**（reverse/full，本套件重点）：流量优先于反汇编、消息结构推断、状态机还原、密码学识别、二进制薄切片、可运行客户端作为正确性闸门。

## 模式开关

配置文件 `~/.pi/agent/ck-pi-redkit.json`（不存在则全量默认）：

```json
{
  "mode": "full"
}
```

| mode       | 注入内容                     |
| ---------- | ---------------------------- |
| `full`     | 核心 + 渗透 + 逆向（默认）   |
| `pentest`  | 核心 + 渗透作战条令          |
| `reverse`  | 核心 + 网络与协议逆向条令    |
| `off`      | 完全停用，零注入零开销       |

改完 `/reload` 生效。
